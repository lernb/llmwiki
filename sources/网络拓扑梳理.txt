六、服务器迁移方案
--------------------------------------------------------------------------------

前提：新接入交换机已从核心交换机对应 VLAN 接口接出，网关 IP 无需修改。

迁移 192.168.1.x 服务器：
  1. 从核心交换机拔下网线
  2. 插入目标接入交换机A（上联核心 Vlan10）
  3. ping 192.168.1.254 验证网关可达

迁移 192.168.3.x 虚机服务器（ESXi）：
  1. 从核心交换机拔下网线
  2. 插入目标接入交换机B（上联核心 Vlan100）
  3. 注意 ESXi 双网卡：
       管理口（192.168.1.x）→ 接入交换机A
       虚机业务口（VLAN100）→ 接入交换机B
  4. ping 192.168.3.1 验证网关可达

================================================================================
查询命令汇总（附注释）
================================================================================


【VLAN 相关】

  show vlan brief
  # 查看所有 VLAN 列表及各 VLAN 包含的端口成员

  show interfaces <端口> switchport
  # 查看指定端口的二层配置，包括 trunk/access 模式、允许的 VLAN 等
  # 示例：show interfaces Gi1/0/15 switchport

  show interfaces <端口> status
  # 查看端口的连接状态、速率、双工、所属 VLAN
  # 示例：show interfaces Gi1/0/15 status


【IP 及路由相关】

  show ip interface brief
  # 查看所有接口的 IP 地址及 up/down 状态（含 SVI 和物理口）

  show ip route
  # 查看完整路由表，包含直连、静态、动态路由

  show ip route <目标网段>
  # 查询特定网段的路由条目
  # 示例：show ip route 192.168.3.0

  show ip route 0.0.0.0
  # 查看默认路由详情

  show ip arp vlan <VLAN号>
  # 查看指定 VLAN 的 ARP 表，可获取 IP 与 MAC 的对应关系
  # 示例：show ip arp vlan 10

  show ip arp | include <关键字>
  # 过滤 ARP 表，查找特定 IP 或端口对应的条目
  # 示例：show ip arp | include Gi1/0/15


【MAC 地址相关】

  show mac address-table vlan <VLAN号>
  # 查看指定 VLAN 的 MAC 地址表，可确认设备接在哪个端口
  # 示例：show mac address-table vlan 100


【堆叠相关】

  show switch
  # 查看堆叠成员列表及各成员角色（Active/Standby）和状态

  show switch detail
  # 查看堆叠详细信息，包含 Stack Port 连接状态及邻居关系
