# 采购申请删除标记清理SQL脚本

本文档分析了一个复杂的SQL脚本，其主要目的是根据销售订单和特定物料，清理（或查询）相关采购申请的删除标记，并提取颜色/规格信息。脚本中还包含对采购信息记录和采购申请的直接删除标记更新操作。

## 脚本核心查询

脚本开头是一个大型`SELECT`语句，从`VBAP`（销售订单行项目）开始，通过多表连接最终输出采购申请相关的字段以及一个拼接的颜色（COLOR）字段。关键逻辑如下：

1. **数据流**: `VBAP` → `EBKN`（账户分配） → `EBAN`（采购申请） → `J_3ABSSI`（批次拆分） → `MARA` / `MAKT`。
2. **过滤条件**:
   - 销售订单号在指定列表中（如`'2100010077'`）
   - 物料号在指定列表中（如`'25FST51003KD931'`）
   - 采购申请未删除（`j.LOEKZ <> 'X'`）
   - 物料描述包含“指定”`（MAKTX LIKE '%指定%'）`
   - 物料组（`H.J_3APGNR`）为ZG、ZCG、ZW、ZCW、ZS、ZCS之一
3. **颜色拼接**: 通过四次子查询，从BOM结构表`J_3ABOMD`中取出最多4个尺寸代码（`SUBSTR(J_3AKORDXL,1,4)`），并用逗号拼接成字符串，存入`COLOR`列。这暗示BOM中可能有多个尺寸，用于描述物料的颜色/规格。
4. **分组**: 按照采购申请号码、行号、物料、客户物料、BOM尺寸等字段分组，使用`MAX`聚合描述等。

### 示例子查询
```sql
(SELECT distinct SUBSTR(M3.J_3AKORDXL,1,4)
 FROM  SAPPRD.MAST M1
 LEFT JOIN SAPPRD.STPO M2 ON ...
 LEFT JOIN SAPPRD.J_3ABOMD M3 ON ...
 WHERE N.MATNR = M1.MATNR AND M2.IDNRK = J.MATNR ... AND rownum = 1)
```
每个子查询获取BOM中对应组件物料的第一行尺寸，然后依次取第2、3、4行。

## 更新操作

### 清除采购信息记录删除标记
```sql
update EINA set LOEKZ=' ' where INFNR='5300092360'
```
将采购信息记录`5300092360`的删除标记置空（去除删除标志）。

### 删除采购申请
```sql
update EBAN set LOEKZ='X' where BANFN='1100442840'
```
将采购申请号`1100442840`的删除标记设置为`X`，表示逻辑删除。

## 其他查询

脚本中还包含了一些单独的`SELECT *`，用于检查特定表的数据，例如：
- 查看STPO中组件`'000000000000273700'`的BOM行
- 查看STKO中BOM抬头`'00052711'`
- 查看MAST中物料`'25FST51003KD931'`的BOM分配
- 查看VBAP中指定销售订单的行项目
- 查看KONH/KONP中条件键值以`'CN00833'`开头的价格条件

这些查询可能是调试或分析数据使用的。

## 应用场景

该脚本很可能用于服装行业（涉及尺寸/颜色BOM），当销售订单变更或物料停用时，需要清理对应采购申请的删除标记，并检查BOM的尺寸信息。`J_3A*`系列表是SAP IS-A（服装行业解决方案）中的表。
