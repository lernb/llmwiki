# 上海网络配置与IP段

**类型：** 概念
**来源：** 上海服务器迁移实施计划.pdf

本文档描述上海机房搬迁后所涉及的网络配置，包括IP地址段划分、VLAN配置、核心交换机接口、防火墙策略及IPSec VPN通道。

## 涉及的IP网段

| 网段 | 用途 | 对应核心交换机接口 |
|------|------|-------------------|
| 192.168.1.0/24 | 原上海业务网段（迁移后保留） | Vlan-interface31 |
| 192.168.3.0/24 | 原上海业务网段（迁移后保留） | Vlan-interface33 |
| 192.168.4.0/24 | 新增网段（迁移后使用） | 未明确指定，推测同核心 |

此外，防火墙内网接口地址为 **172.18.10.40**，用于内网通信与互联网出口。

## 核心交换机VLAN配置

核心交换机上需开启对应VLAN接口，命令如下：
```
interface Vlan-interface31
 undo shutdown
interface Vlan-interface33
 undo shutdown
```
确保VLAN接口处于up状态，服务器网关指向对应接口IP。

## 防火墙与IPSec VPN

防火墙（AF）需进行以下调整：
- 删除原192.168.1.0/24及192.168.3.0/24网段在IPSec VPN策略中的旧条目。
- 上海侧AF同步更新配置，重建或修改IPSec VPN隧道。
- 检查隧道状态（通过AF管理界面或命令行）。

## 网络互通验证要点

1. **内网访问**：总部或其他分部必须能够访问上海192.168.1.x的服务器。
2. **上海服务器出访**：上海服务器必须能够访问其他网段（如办公内网、生产网）。
3. **防火墙连通性**：上海服务器需能ping通防火墙内网接口（172.18.10.40）。
4. **互联网访问**：确保上海服务器可以访问外网（如软件更新、远程同步）。
