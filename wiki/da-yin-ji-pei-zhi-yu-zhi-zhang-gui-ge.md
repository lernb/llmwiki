# 打印机配置与纸张规格

本文档记录 Mis2 系统中与抖音面单打印相关的打印机配置以及纸张规格设置方法。

## Mis2 打印机配置

在 **配送扫描装箱** 页面，点击顶部 **“配置打印机”** 按钮，弹出“配置默认打印机”窗口，按以下设置选择对应打印机：

| 项目 | 推荐打印机 |
|------|------------|
| 箱唛打印机 | Canon LPB3000 或 Canon LBP2900 |
| A4打印机 | 与箱唛打印机相同 |
| 中通快递运单打印机 | Deli DL-888B |
| 唯品会运单打印机 | Deli DL-888B |
| 顺丰运单打印机 | Deli DL-730C |
| EMS运单打印机 | Deli DL-888B |
| 跨越运单打印机组件 ID | 无需填写 |

## 配置打印机纸张规格

1. 在桌面双击打开 **控制面板**。
2. 点击 **“查看设备和打印机”**，打开“设备和打印机”窗口。
3. 右键点击对应打印机的图标，选择 **“打印机属性”**，打开属性窗口。
4. 点击 **“首选项”** 按钮。
5. 在弹出的窗口中点击 **“新建”** 按钮。
6. 输入对应名称，设置对应尺寸大小：
   - **中通运单**：70mm × 120mm
   - **顺丰运单**：100mm × 150mm
7. 点击 **“确定”** 关闭所有窗口。
