# 服务器迁移项目

**类型：** 项目
**来源：** 上海服务器迁移实施计划.pdf、综合项目文档

服务器迁移项目是信息技术部门主导的IT基础设施升级工作，旨在将业务系统从旧有服务器迁移至新硬件或新数据中心环境。本项目的成功实施需要周密的计划、严格的执行顺序和充分的验证测试。

## 项目概述

迁移项目通常包含以下阶段：
1. **前期调研与评估**：分析现有服务器角色、系统依赖、网络拓扑、数据量等。
2. **方案设计**：确定目标环境（如新机柜、虚拟机平台）、网络规划（IP地址段、VLAN）、迁移策略（冷迁移/热迁移）。
3. **准备与预实施**：采购硬件、搭建临时测试环境、备份数据。
4. **正式迁移**：按照[[上海服务器迁移实施计划]]执行设备上架、上电、服务启动、检查验证。
5. **网络切换与优化**：调整防火墙策略、IPSec VPN配置、路由，确保内网与互联网互通。
6. **收尾与文档**：清理旧设备，更新服务器清单、网络拓扑文档。

## 上海迁移案例

最近一次迁移涉及上海机房的服务器重新部署至3号机柜，主要包括：
- **虚拟化平台**：基于[[VMware虚拟化平台]]的域控服务器和业务应用服务器。
- **数据库服务器**：承载核心业务数据库。
- **业务应用服务器**：运行企业应用系统。
- **网络调整**：核心交换机VLAN 31/33接口启用，防火墙IPSec VPN隧道重建。

详细操作步骤见[[上海服务器迁移实施计划]]。

## 关键要素

| 要素 | 说明 |
|------|------|
| 硬件环境 | 3号机柜、机柜交换机、核心交换机 |
| 网络规划 | 192.168.1.x/24、192.168.3.x/24、192.168.4.x/24 |
| 核心设备 | 核心交换机（Vlan-interface31/33）、防火墙（AF） |
| 服务依赖 | 域控AD、DNS、DHCP、数据库、业务应用 |
| 验证手段 | ping、nslookup、dcdiag、业务登录测试 |
